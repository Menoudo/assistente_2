# Changelog

Все значимые изменения в **waiting-mcp** документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.2] - 2026-10-21

### Fixed

- Сохранение произвольного Markdown в заметках и истории без потери заголовков.
- Валидация ID во всех путях чтения и записи; ограничение файловых операций корнем базы.
- Проверка обязательных полей перед записью, чтобы ошибочный вызов не повреждал список.
- Атомарное применение частичных обновлений и межпроцессная блокировка для сохранения истории и статуса.
- Очистка заметок и сроков, возврат фактически сохранённого времени обновления.
- Расчёт просрочки без лишнего дня; единый календарь обзора с настраиваемым часовым поясом.

### Added

- Регрессионные проверки хранилища и MCP, конкурентных обновлений и нескольких процессов.

## [0.2.1] - 2026-07-28

### Fixed

- `waiting_list` с `status: done` возвращал 0 записей: `IncludeDone` отсекал done даже при явном фильтре по статусу.

## [0.2.0] - 2026-07-28

### Added

- Завершённые ожидания переносятся в `data/waiting/done/` при `waiting_complete`.
- Фильтр `include_done` в `waiting_list` для чтения архивных карточек.
- При deploy копируются `README.md` и `CHANGELOG.md` в целевую директорию.

### Changed

- Активные и завершённые карточки хранятся в разных каталогах markdown.

## [0.1.0] - 2026-07-24

### Added

- MCP-сервер **waiting-mcp** с markdown-хранилищем GTD Waiting For.
- CRUD для ожиданий и людей, `waiting_review_due`, история проверок.
- Транспорты stdio и HTTP (Streamable HTTP).
- Скрипт `scripts/deploy.sh` и GitHub Actions workflow для тестов.
